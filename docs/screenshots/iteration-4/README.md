# Iteration 4 — Visual proof

Screenshots captured from a live run of the app (Go backend + Vite dev server) after
uploading the sample FIT files in `docs/examples/` and seeding a few different dates
so the calendar shows real, varied activity.

1. `01-dashboard.png` — Redesigned Dashboard: current totals, recent trainings, and a
   compact "This month" calendar preview linking into the full Calendar.
2. `02-sidebar.png` — Redesigned app shell/sidebar with Dashboard, Calendar,
   Trainings, and Settings navigation and a clear active state.
3. `03-calendar.png` — The new Calendar page: a monthly grid with month navigation
   (prev/next/today) and training chips on the days that have activity.
4. `04-calendar-day-activity.png` — Close-up of a calendar day containing a real
   training entry (name + distance shown directly on the chip).
5. `05-training-detail-from-calendar.png` — The training detail page reached by
   clicking a training chip directly from the calendar.
6. `06-training-detail-full.png` — Full training detail page: metadata, metrics
   (distance/duration/elevation/heart rate), the time-series chart, and the track
   view, all reusing the shared UI components introduced in this iteration.
